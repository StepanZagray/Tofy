# P2 v16 — dynamics stability

Builds on v15 spatial grid latents with training/export fixes from the v15 post-mortem.

## Changes vs v15

| Area | Fix |
|------|-----|
| **Latent scale** | Per-batch RMS norm on encoder output and dynamics `y` |
| **Open-loop train** | Per-step Huber cap (10), error reset at MSE>5, teacher reset uses **encoded next frame** (not current) |
| **Rollout horizon** | Sequential max **8** (was 16); retarget max **4** |
| **Teacher mix** | Retarget keeps higher AR forcing (0.75→0.5) when enabled |
| **Default curriculum** | **No retarget** — optional via `RETARGET=1` or `--lessons ...,retarget` |
| **Export** | `model.best.safetensors` saved after falsification; eval/train export prefer it over post-retarget weights |
| **SIGReg** | Script default **0.003** (v11-scale; v15 used 0.01) |

## Run

```bash
scripts/p2_v16_train_eval.sh
# OUTPUT_DIR=p2-output-v16 DEVICE=cuda

RETARGET=1 scripts/p2_v16_train_eval.sh
```
