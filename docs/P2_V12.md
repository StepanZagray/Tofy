## Model changes (v12)

Applied to `WorldModel` before the overnight chain:

| Change | Rationale |
|--------|-----------|
| **Dual TRM blocks** (`block_z`, `block_y`) | Separate inner scratch refinement from outer state update |
| **Encoder dual-pool** (flatten + global avg/max per channel) | Preserve sparse grid peaks; modest capacity bump |
| **`y` warm-start from `x`** | Zero-init made early recursion nearly inert |
| **Default `delta_dynamics` + `stop_grad_dynamics_target`** | Stabilize autoregressive latent manifold (v11 analysis) |

Old checkpoints (v8–v11) are **not compatible** (encoder proj size + block split).
