# P2 v13 — v11 architecture + tighter Q threshold

v12 dual-block / dual-pool encoder regressed rollout vs v11-control. v13 **reverts
the model** to the v11 stack and changes **one training knob** vs v11-control:

| | v11-control | v13 |
|--|-------------|-----|
| Architecture | single `block`, flat encoder pool | same |
| Lessons | 5 (no exploration) | same |
| `delta_dynamics` | false | false |
| `stop_grad_dynamics_target` | false | false |
| `q_mse_threshold` | **0.25** | **0.05** |
| `hidden_dim` | 128 | 128 (CLI default) |

**Gate:** beat v11 on rollout-8 (< 0.17) while improving Q calibration (not saturated).

## Train

```bash
cargo run --release --features cudnn -- p2-train \
  --device cuda --hidden-dim 128 --action-dim 32 \
  --physical-batch 1024 --grad-accum 1 --steps-per-lesson 4096 \
  --checkpoint-every-steps 100 \
  --output-dir p2-output-v13
```

Defaults supply v11 lessons and `q_mse_threshold=0.05`.

## Eval

```bash
cargo run --release --features cudnn -- p2-eval \
  --checkpoint p2-output-v13/model.safetensors \
  --train-config p2-output-v13/config.json \
  --device cuda --synthetic-episodes 64 --physical-batch 64 \
  --ptrm-k 1,2,4,8 --q-mse-threshold 0.05 \
  --output p2-output-v13/eval_report_64ep_v3.json
```

## Baseline (do not overwrite)

`p2-output-v11-control/` — rollout MSE @ 8 = **0.17**, one-step **0.026**.
