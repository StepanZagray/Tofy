# P2 v15 — spatial simulation fidelity

Builds on v14 with changes aimed at **realistic short-horizon simulation** (not 128-step planning).

## Model

- **Spatial grid latent** `B×C×8×8` (conv TRM block on patch grid; no global pool before dynamics)
- Q/event heads pool spatially for readout

## Training

- **SIGReg** on flattened spatial latents (`--sigreg-weight 0.01` in v15 script)
- **Open-loop rollout** horizon ramps **2→4→8→16** (sequential/retarget)
- **AR forcing**: scheduled reset to real encodings during rollout training (`teacher_mix` 0.5→0)
- **Q surprise loss**: penalize high Q when latent MSE is large (anti-hallucination)

## Eval (`p2.eval_report.v5`)

| Metric | Meaning |
|--------|---------|
| `rollout` | Open-loop MSE @4/@8/@16 (model simulates itself) |
| `closed_loop` | Re-encode real frame each step @4/@8/@16 (matches ARC play) |
| `q_surprise` | Q when unreliable vs reliable; `confident_error_rate` |
