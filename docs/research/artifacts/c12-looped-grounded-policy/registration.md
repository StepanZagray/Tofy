# C12 grounded recurrent policy learning: single-seed feasibility screen

Registered before implementation of the training/evaluation runner and before any C12 population generation, batch qualification, optimizer update or evaluation. The separate implementation claim preceded the model-interface work. This is an adaptation motivated by completed Tofy evidence, not a paper-faithful replication or an architecture-optimality claim.

## Claim and mathematical prerequisites

The initial core plus the already fitted C10 true-role spatial policy can be trained end-to-end using policy cross-entropy to use visible demonstrations when controls change, reaching high terminal accuracy on familiar and unseen control-map combinations at unseen layouts. The experimental unit for uncertainty is a query layout with every map variant, not an individual variant. One training seed is a screen, never method promotion.

The task is the existing 8x8-cell synthetic maze rendered as64x64 palette pixels, distance exactly1, four actions, three distinct unblocked nonterminal demonstrations. No ARC environment or public level is accessed. The model sees only seven frames and existing public role/action/coordinate/time metadata. Query appearance and demonstrated action IDs/order are identical across every map for a fixed seed/id. Full inputs differ through visual transitions; all three demonstrations identify the bijection. Map IDs, simulator controls, role coordinates, hashes, labels and episode IDs are audit/scoring fields only.

Fit maps are [0,2,4,5,7,8,9,10,13,14,15,16,18,19,21,23]. Heldout maps are [1,3,6,11,12,17,20,22]. Every action-direction pair occurs four times in fit and twice in heldout; identity0 is in fit. Any deterministic query-plus-action-ID-only policy therefore scores exactly25% over either complete group. Always choosing the undemonstrated action scores25% overall,100% on omitted-action queries and0% on demonstrated-action queries; the best action-ID-only policy on the demonstrated subset scores1/3. Subset performance alone cannot demonstrate elimination. A cleared-support control changes the input distribution; paired factual supports with changed labels supply the stronger action-binding evidence.

No mathematical argument establishes this optimizer's success. The cheapest prerequisites are exact forward translation, a connected and numerically useful gradient path, valid paired populations, and a bounded device/batch qualification. Failed prerequisites prevent training.
