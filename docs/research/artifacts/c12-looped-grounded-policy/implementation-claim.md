# C12 implementation claim and training hypothesis

Defined before implementation. This is the next prerequisite after C11's registered CUDA confirmation, with independent raw verification accepted and final publication being sealed. C11's two true-role readouts each selected both roles and actions correctly on 768/768 fixed-control synthetic episodes. The native heads remain 188/768 and 209/768. C11 does not establish changing-control inference or useful recurrent depth.

## Exact implementation claim

A trainable spatial-policy module can consume the existing differentiable post-normalization current tokens of the shared-depth looped core, execute the same two-query attention/affine policy as the fixed C10/C11 head, and propagate policy-loss gradients into both core and head. The frozen cached-head evaluator retains its no-tracked-input contract. This is an interface and numerical claim, not a performance improvement claim.

The exact-arithmetic forward equivalence follows by retaining the same queries, dot-product scale 1/sqrt(128), token softmax, two weighted pools in their existing order, and affine output. A differentiable graph alone does not prove useful or nonzero gradients. Before training, require measured CUDA parity for logits and pooled features at absolute tolerance 1e-4 plus relative tolerance 1e-5, attention at 1e-5 plus 1e-5 relative, and exact action argmax. Test batch one and a batch greater than one using already accessed inputs. Require finite nonzero core and head gradients from policy CE and an actual disposable optimizer update changing both, followed by exact initialization restoration. Preserve legacy forward outputs and gradients when factoring a feature-only path. No GPU launch is authorized by implementation alone: source review/push, full device/profile qualification, final registration and data bindings precede it.

Implementation scope: a trainable spatial policy, a reusable differentiable feature path if needed to avoid unused heads, and an explicit profiler contract for active core/spatial-policy gradients and inactive ordinary policy/value/reward/dynamics parameters. All wired profiling remains enabled. No LLM, oracle parser, hidden map, role index, episode identifier or external planner enters learned inference. Synthetic role labels were used to fit the warm start; that privilege remains disclosed.

## Next empirical hypothesis, not yet a launch registration

Initialize the common untrained core (SHA256 4cd502f7a76fe3dd9729f6693e9d707c670972f7ebe58ad1cbdde37ea2bb2802) and its exact C11 initial/c10_true 1,284-parameter F32 policy. Train policy cross-entropy end-to-end at four shared loops on fresh distance-one synthetic mazes with changing control permutations. No new role/map supervision, dynamics/reward/value loss or public ARC data is included. Ordinary unused heads receive no updates. Historical native/C9 outcomes are context, not matched causal comparator arms.

Candidate bounded screen: one seed, 1,150 updates, effective batch64 (73,600 rows), four paired query layouts times all16 fit maps per update. Measure the largest stable physical batch with at least512MiB reserve and below85C on AC; reset initialization after disposable batch trials. Record physical microbatches/accumulation and preserve row-weighted gradient normalization. Exact optimizer/data/evaluation seeds, terminal checkpoint, failure gates and budgets must be frozen in registration before launching.

Fix the map split before data generation: fit [0,2,4,5,7,8,9,10,13,14,15,16,18,19,21,23]; heldout [1,3,6,11,12,17,20,22]. Each action-direction pair occurs four times in fit and twice in heldout, with identity0 in fit. This is a direction relabeling by (0,1,3,2) of the existing balanced split.

For a paired seed/id, task.rs generates the same query and the same demonstrated action IDs/order across maps. Only visible support transitions change. Therefore every deterministic query-plus-action-ID-only policy has exactly25% one-step accuracy over each complete balanced group. Three distinct unblocked demonstrations identify the four-action bijection. Always choosing the undemonstrated action nevertheless scores100% on the omitted-action subset and25% overall; that subset alone cannot show learned elimination. Report this shortcut and use all-query performance and paired factual map variants as the main evidence. A cleared-support ablation is an additional distribution-changing control.

The eventual screen will distinguish training fit, familiar maps on unseen layouts, and unseen map combinations on unseen layouts; confidence intervals resample whole query groups with their map variants. A proposed conjunctive feasibility gate is terminal accuracy at least90% on each population and positive paired bounds against the exact frozen warm start and cleared-support controls on transfer populations. A single seed is a screen only. Failure to fit leaves optimization/grounding unresolved; good fit with failed transfer rejects this bounded transfer recipe, not the architecture's information capacity. No outcome establishes ARC performance, a world model, planning or useful recurrence. The final registration will specify exact populations, thresholds, uncertainty, captures, time limits and stop rules before model execution.
