# Data formats

## ARCEngine synthetic shards (ADR 0005 §2.6)

Writer: `python/tofy_arc3/synth/shard.py` (`python -m tofy_arc3.synth.generate
--seed S --games N --out DIR`). Reader: `src/p2/synthetic_shards.rs`
(`SyntheticShardPool::load`, `cached_pool`). Sample: `runs/p2/synth-sample-20260903/`
(`manifest.json` is committed; `*.safetensors` is gitignored and regenerated by
the same command with `--seed 1 --games 20`).

### Directory layout

```
DIR/
  manifest.json            sidecar (validated, see below)
  shard-00000.safetensors  one or more shards, <= 50 000 rows each
  games.json               generator specs (not read by the loader)
```

### Tensor contract (exact; the loader fails closed on any deviation)

| tensor              | dtype | shape       | meaning                                              |
|---------------------|-------|-------------|------------------------------------------------------|
| `frames`            | u8    | `[N,64,64]` | current frame, colour indices `0..=15`               |
| `next_frames`       | u8    | `[N,64,64]` | frame after the action                               |
| `actions`           | u8    | `[N,3]`     | `(id, x, y)`; `id` in `0..=7` (0 = RESET); `x,y = 255` unless `id == 6` |
| `available_actions` | u8    | `[N]`       | bit0 = RESET, bit i = ACTIONi (ADR 0005 §1.6)        |
| `episode`           | u32   | `[N]`       | episode id; must appear in `manifest.episodes`       |
| `level`             | u16   | `[N]`       | level index within the episode                       |
| `transition_index`  | u32   | `[N]`       | chronological index within the episode (unique)      |
| `rule_id_lo`        | u32   | `[N]`       | low 32 bits of the hidden-rule hash                  |
| `rule_id_hi`        | u32   | `[N]`       | high 32 bits; `rule_id = lo | hi << 32`, never 0     |
| `level_completed`   | u8    | `[N]`       | 0/1 (validated, not used as a label)                 |
| `game_over`         | u8    | `[N]`       | 0/1 (validated, not used as a label)                 |

The name set must equal exactly these eleven tensors; dtypes are compared
against the safetensors header (`U8`/`U16`/`U32`), so a `level` column stored as
u32 is rejected even though candle would load it. Rows may appear in any order
within a file.

### Manifest contract

Required and validated:

- `source == "tofy_synth_arcengine"`.
- `public_game_ids_excluded` must contain all 25 public ARC-AGI-3 game ids
  (hard-coded in `synthetic_shards::PUBLIC_GAME_IDS`, copied from
  `python/tofy_arc3/synth/public_games.py`); `public_game_ids_intersection`, if
  present, must be empty.
- Every id in `game_ids` and `episodes[].game_id` must start with `tsyn-` and
  must not be a public game id. Any clash rejects the whole directory.
- `game_id_prefix`, if present, must be `tsyn`.
- `shards[]`: `file` (plain `.safetensors` name); optional `rows` and `sha256`
  are checked against the file when present.
- `episodes[]`: `episode` (unique), `game_id`; optional `rule_id` and
  `available_actions` are cross-checked against every row of that episode;
  optional `background` (letterbox colour) overrides the border heuristic.
- `total_rows`, if present, must equal the sum of shard rows.
- `seed` seeds the per-row context-length draw (default 0 when absent).

Other keys (`generator`, `policy`, `rule_census`, `twin_pairs`, ...) are
carried but not validated.

### Row conversion (`TransitionSample`)

- `current`/`next`: the whole 64x64 frame is content (`content_rect` =
  `(0,0,64,64)`, ADR 0005 §1.1).
- `action`: `ArcAction(id, x, y)`; `255` becomes `None`. RESET rows (`id == 0`)
  are dropped (`ArcAction` has no RESET) and counted in
  `SyntheticShardStats::reset_rows_skipped`; they do not enter Context Windows.
- `noop = Some(current == next)`.
- `goal_features` are all zeros and `goal_satisfied`/`goal_failed`/`exhausted`
  are `None`: shards carry no hidden-goal labels yet.
- `provenance`: `source_kind = family = "synthetic_shard"`,
  `trajectory_id = "synthetic_shard/<game_id>/<episode>"`, `rule_id`,
  `level_index = level`, `available_actions` = the shard mask (kept through
  augmentation), `background_color` = manifest `episodes[].background` if
  present, else the most frequent colour on the frame border (ties: lowest
  index), `operator = None`.
- `seed` = manifest seed, `episode_id = episode`, `transition_index`,
  `split = Train`.
- Context Window (ADR 0005 §1.5): the `K` chronologically preceding kept rows
  of the same `episode` (ordered by `transition_index`, crossing level
  boundaries), `K ~ Uniform{0..16}` with `P(K=0) >= 0.10` drawn per row from a
  ChaCha8 stream seeded by `(manifest.seed, episode, transition_index)`; the
  same draw as Learning Histories (`data::sampled_context_len`).

### Stream composition

`MixedStreamKind::SyntheticShards` has weight 0 in
`adaptation_v6_stream_schedule` and `foundation_v2_stream_schedule` (ADR 0005
§2.6: it stays 0 until the shard generator passes the §5.1 memorization
diagnostic on its own twins). A schedule with a non-zero `synthetic_shards`
weight requires `MixedStreamConfig { data_contract_v6: true,
synthetic_shards_dir: Some(dir), .. }` and the `Train` split. Each unit is up to
`SYNTHETIC_SHARD_UNIT_ROWS = 8` contiguous chronological rows of one
deterministically chosen episode, augmented by `augment_v5_unit` like a
Learning History unit: one D4 symmetry and one uniform permutation of all 16
colours (index 0 included) shared by the rows and their Context Windows;
ACTION6 coordinates are conjugated. `background_color` is the permuted
letterbox colour. The sidecar `operator` of a shard row is a placeholder
(`Toggle`, colours 0, `empty_color` = letterbox) with no semantic meaning; v6
conditioning is UNKNOWN regardless (ADR 0005 §1.4).

Legacy and v6 batches with a zero shard weight are byte-identical to the
pre-shard composer (`mixed_stream_generation_content_digest_snapshot`,
`v6_mixed_stream_content_digest_snapshot`).
